# Volier Automações — versão estática

Esta versão mantém o layout da última versão do site enviada pelo usuário, mas remove Flask/Python para que o projeto possa ser publicado como Static Site.

## Rodar no VS Code

1. Abra esta pasta no VS Code.
2. Instale a extensão **Live Server**.
3. Abra `index.html`.
4. Botão direito → **Open with Live Server**.

Também funciona abrindo `index.html` diretamente no navegador.

## Render

Crie um **Static Site** e publique a pasta raiz.

- Build Command: vazio
- Publish Directory: `.`

Depois associe:
- `volierautomacoes.com.br`
- `www.volierautomacoes.com.br`
